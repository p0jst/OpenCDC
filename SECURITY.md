# Security

OCDF is documentation, a static website and three browser tools. The tools run entirely in the browser and send nothing anywhere, but they do read files and links that users give them, so a flaw in them can matter.

## Reporting a problem

Report security problems in the website, the tools or the build privately, through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue for them.

Include what you found, how to reproduce it, and which version or page it affects. This is a personal project maintained on a best-effort basis; you will get an acknowledgement, and fixes are recorded in the [changelog](CHANGELOG.md).

## Not a security problem

Errors in the framework's content, such as a wrong legal reference or an outdated annex, are corrections, not vulnerabilities. Open a normal issue for those; see [Contributing](CONTRIBUTING.md).
